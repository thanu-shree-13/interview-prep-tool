# AI Interview Prep Tool

An AI-powered interview preparation platform built with React, Node.js, MongoDB, Firebase, and Gemini AI.

## Features
- 🤖 AI-generated interview questions for any job role
- 🎤 Voice input support (Web Speech API)
- ✅ AI scoring and feedback on answers
- 📊 Session history and progress tracking
- 🔐 Firebase authentication

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB Atlas
- AI: Grok API
- Auth: Firebase
- Deployment: AWS (EC2 + Amplify)

## How to Run
1. Clone the repo
2. Add .env file in backend with MONGODB_URI and GEMINI_API_KEY
3. Run backend: cd backend && npm run dev
4. Run frontend: cd frontend && npm start
